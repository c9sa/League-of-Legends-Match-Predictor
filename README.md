# League-of-Legends-Match-Predictor

Small PyTorch neural network for predicting League of Legends match outcomes.

## Tools

- PyTorch
- pandas
- scikit-learn
- matplotlib

## Flow

1. Data Loading and Preprocessing
2. Define Model
3. Train & Evaluate
4. Model Optimization
5. Visualization & Interpretation
6. Model Saving & Loading
7. Hyperparameter Tuning
8. Feature Importance

## Results

- Baseline Test Accuracy: 0.49
- With L2 Regularization: 0.50
- Hyperparameter Tuning (Learning Rate): 0.525

## Run

Open `Final Project League of Legends Match Predictor.ipynb` in Jupyter and run the cells in order.
